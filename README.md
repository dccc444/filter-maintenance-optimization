# filter-maintenance-optimization

数学建模 B 题"过滤设备监测"的可复现分析项目。当前已实现第一问和第二问：

## 第一问：数据分析与指标构造

- 10 台过滤器小时级数据质量检查与异常标记
- 鲁棒日尺度聚合
- 年/半年谐波季节性检验与频谱辅助判断
- 按维护周期估计自然下降率
- 中维护、大维护的反事实事件研究
- 维护效果持续时间与右删失分析
- 维护前后等长窗口下降率变化及设备聚类检验
- 长期维护后上包络线衰减
- 设备级透水率变化指标体系（9 项指标）
- 自动生成论文可用表格、图片和 Markdown 报告

运行：

```powershell
.\.venv\Scripts\python -m src.problem1.run
```

## 第二问：寿命预测模型

- 双状态退化模型（不可逆性能上限 $C(t)$ + 可逆堵塞 $F(t)$ + 季节效应 $S(t)$）
- 精确复用第一问四个年/半年谐波系数
- 从第一问指标估计 $\alpha/\beta/MG/\sigma$，并显式建模维护损伤
- 从当前维护状态继续固定维护规律，不重新启动完整间隔
- 双条件寿命终止准则（365 日平均 < 37 且大维护后 30 日平均 < 37）
- 1000 次蒙特卡洛仿真，含参数不确定性扰动
- Kaplan–Meier 右删失处理
- 训练期限定、无时间泄漏的一年期回测
- 10 台设备寿命预测 + 95% 预测区间
- 可供第三问和第四问调用的寿命、透水率和年均成本接口
- 机器可读接口清单位于 `outputs/problem2/problem3_4_interface.json`

运行：

```powershell
.\.venv\Scripts\python -m src.problem2.run --n-runs 1000
```

主要输出：

```text
outputs/problem2/
├─ figures/              # 5 张论文可用图片
├─ tables/               # 寿命预测表、参数表、回测指标等
└─ 第二问分析报告.md
```

论文正文位于 `paper/第一问论文正文.md` 和 `paper/第二问论文正文.md`。

## 分析原则

1. 维护引起的透水率跳升不是异常值
2. 小时缺失不做全局线性填补，趋势分析使用每日中位数
3. 周期识别可使用短缺口插值，但维护效果估计只使用实际观测
4. 维护效果以维护前趋势外推为反事实，不直接用简单前后均值下结论
5. 只有约两年数据，年周期结论同时报告显著性、振幅和频谱证据
6. A4、A8 无大维护记录；第一问保持缺失，第二问采用明确标注的总体情景插补
7. 自然老化与维护损伤不可完全识别，基准损伤占比为 20%，第三、四问必须做情景分析
8. 寿命预测含参数不确定性和右删失处理，不以点估计代替区间
9. 回测参数只能使用切分点以前的数据，禁止时间泄漏
