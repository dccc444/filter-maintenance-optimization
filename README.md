# filter-maintenance-optimization

数学建模 B 题“过滤设备监测”的可复现分析项目。当前已实现第一问：

- 10 台过滤器小时级数据质量检查与异常标记；
- 鲁棒日尺度聚合；
- 年/半年谐波季节性检验与频谱辅助判断；
- 按维护周期估计自然下降率；
- 中维护、大维护的反事实事件研究；
- 长期维护后上包络线衰减；
- 设备级透水率变化指标体系；
- 自动生成论文可用表格、图片和第一问 Markdown 报告。

论文正文初稿位于 `paper/第一问论文正文.md`，包含模型公式、统计结果、表格、图号以及与第二问的衔接说明。

## 数据

原始题目附件位于 `B题附件/`：

- `附件1.xlsx`：10 个工作表，记录小时级透水率；
- `附件2.xlsx`：中维护和大维护记录。

程序不会改写原始附件。所有清洗和派生数据写入 `outputs/problem1/`。

## 环境与运行

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m src.problem1.run
```

快速测试：

```powershell
.\.venv\Scripts\python -m pytest
```

主要输出：

```text
outputs/problem1/
├─ figures/       # 论文可用图片
├─ tables/        # CSV 结果表
├─ processed/     # 清洗后的小时/日尺度数据
└─ 第一问分析报告.md
```

## 分析原则

1. 维护引起的透水率跳升不是异常值；
2. 小时缺失不做全局线性填补，趋势分析使用每日中位数；
3. 周期识别可使用短缺口插值，但维护效果估计只使用实际观测；
4. 维护效果以维护前趋势外推为反事实，不直接用简单前后均值下结论；
5. 只有约两年数据，年周期结论同时报告显著性、振幅和频谱证据；
6. A4、A8 无大维护记录，设备级大维护指标保持缺失，不人为补造。
